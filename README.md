# Google Play Store App Insights Using PowerBI

## Project Overview

The Google Play Store App Insights project focuses on transforming raw Google Play Store data into an interactive Power BI dashboard that provides meaningful insights into app performance, user behavior, ratings, installs, pricing strategies, content suitability, and update trends. The dashboard helps developers, marketers, and business stakeholders make data-driven decisions.

## Objective

* Analyze application ratings and popularity.
* Identify high-performing app categories.
* Study install behavior across app segments.
* Compare free and paid applications.
* Understand pricing and app size distribution.
* Analyze update trends and content ratings.
* Build an interactive dashboard for business decision-making.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Data Modeling
* Interactive Dashboards
* KPI Cards
* Bar Charts
* Pie Charts
* Scatter Plots
* Tables & Matrix Visuals

## Process

1. Imported the Google Play Store dataset into Power BI.
2. Performed data cleaning and transformation using Power Query.
3. Converted Size, Installs, Price, and Last Updated columns into appropriate data formats.
4. Removed invalid records and handled missing values.
5. Created data models and calculated measures.
6. Designed interactive dashboard pages for Ratings, Installs, Pricing, Size Analysis, and Update Trends.
7. Developed KPIs and visualizations to identify market trends and app performance patterns.

## Key Insights

* The Play Store ecosystem is dominated by a few categories with significantly higher installs and ratings.
* Most applications fall within the 4–5 rating range, indicating generally positive user feedback.
* Game applications receive the highest number of installs.
* Free applications dominate both app count and total installs.
* Higher app prices do not necessarily result in higher ratings.
* Medium-sized applications often achieve stronger adoption rates.
* Regular app updates contribute to stronger user engagement and platform relevance.

## Recommendations

* Focus on maintaining ratings above 4.0.
* Release frequent application updates.
* Monitor user reviews and feedback regularly.
* Optimize application size for better adoption.
* Invest in high-growth app categories.
* Track update frequency as a key success indicator.
